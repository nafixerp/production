# Role & Permission Matrix

| Role | Permissions |
|---|---|
| Super Admin | Full access |
| Owner/Director | Dashboard, reports, approvals |
| Factory Manager | Production, QC, inventory, reports |
| Production Supervisor | Production order, stage entry, WIP |
| Store Manager | Inventory, batches, expiry, transfers |
| Purchase Manager | Suppliers, PO, GRN, purchase invoice |
| QC Manager | Incoming, process, final QC, recall |
| Sales Manager | Sales, customers, delivery |
| E-Commerce Manager | Online products, orders, coupons |
| Accountant | Accounts, GST, financial reports |
| HR Manager | Staff, attendance, payroll |
| Delivery Staff | Delivery note, route delivery |
| Auditor | Read-only reports and audit logs |
